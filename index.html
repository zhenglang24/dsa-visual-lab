比较类下界

  • ▸ 任何比较排序最坏至少 O(n log n)
  • ▸ 归并、堆达到下界
  • ▸ 快速平均最优，但最坏 O(n²)

非比较突破

  • ▸ 计数、桶、基数利用数据特征
  • ▸ 特定条件下可达 O(n)
  • ▸ 适用整数、范围小

稳定性速记

  • ▸ 稳定：冒泡、插入、归并、计数、桶、基数
  • ▸ 不稳定：选择、希尔、快速、堆
  • ▸ 口诀："冒插归，计桶基"六稳定

📖 使用指南 · 详细教程

📊 排序可视化

功能简介：演示 10 种经典排序算法的执行过程，代码、变量、条形图、文字解说同屏联动，支持单步、回放与性能分析。

v5 同屏联动（双栏工作台）

排序页采用左右双栏：左栏是算法选择、条形图、进度条、控制按钮与数据设置；右栏（滚动时固定在视口）是代码卡 + 变量卡 + 解说卡 + 步骤时间线。单步时不用来回翻页，一眼就能同时看到「条形图怎么动 / 哪一行代码在跑 / 变量变成多少」。

  • 代码卡：支持 Python / C / Java 三种语言切换，当前执行行自动高亮并在代码框内部滚动到位（不会带着整页跳）。
  • 变量卡：只显示当前算法真正用到的变量（如冒泡 i / j、快速 pivot / left / right、归并 left / right / mid），无关变量自动隐藏。
  • 解说卡：大字解说 + 步骤号 + 操作类型徽章（比较 / 交换 / 写入 / 标记有序）。
  • 步骤时间线：实时列出最近 12 步，点击任意一步即可回看该帧；排序进行中也能回看，预览结束后点「⏵ 回到实时」继续。
  • 布局切换：右上角「▥ 双栏 / ▤ 单栏」按钮（快捷键 L），单栏时右栏内容回到页面下方，浏览器会记住你的选择。

操作步骤

  1. 选择算法：点击顶部按钮（冒泡、选择、插入……）切换。
  2. 准备数据：使用“规模”滑块调整数组长度（5~100），或选择预设（随机、逆序、几乎有序、重复），也可在“手动”框中输入逗号分隔的数字（如 5,1,4,2,8）并点击“应用”。
  3. 开始排序：点击“开始”，观察条形图、右栏变量、代码高亮、解说与时间线同步变化。
  4. 单步调试：点击“暂停”后用“下一步”逐步执行，随时可用“上一步”回到上一帧对照；排序结束后，“上一步 / 下一步”自动变成回放游标。
  5. 回放历史：排序完成后出现回放滑动条，拖动可回溯任意步骤。
  6. 性能雷达图：排序结束后自动生成五维效率图（以 n² 为比较/交换基准），并做一次结果校验（单调性 + 元素多重集一致），通过时提示“✅ 排序结果校验通过”。
  7. 多次运行统计：展开“多次运行”内联面板，填写次数（1~100）后点“开始统计”，查看平均耗时、比较/交换次数的统计图表（不再弹窗输入）。
  8. 音效开关：点击“🔊 音效”后，比较/交换会发出不同音调的声音，用耳朵感受算法节奏。
  9. 进度条：可视化区域下方的金色进度条实时显示已排序比例。
💡 提示：快捷键 Space（暂停/继续）、→（下一步）、←（上一步）、R（重置）、L（双栏/单栏）、T（主题）、1~8（切换标签页）。

📋 算法对比

功能简介：以表格形式展示十大排序算法的时间复杂度、空间复杂度和稳定性，附带总结卡片和复杂度增长曲线图。

使用方法

直接浏览表格和下方的总结卡片。表格下方新增「复杂度增长曲线图」，用 sqrt 压缩纵轴展示 O(1) 到 O(n²) 的增长差异，一眼看懂为什么 O(n²) 算法在大数据下不可接受。

🌳 二叉搜索树 (BST)

功能简介：可视化 BST 的插入、查找、删除与遍历，支持单步调试并同步高亮操作代码，实时显示节点数和树高。

操作步骤

  1. 在输入框中输入一个整数值；点“🌱 示例树”或“🎲 随机建树”可一键得到一棵能直接玩的树。
  2. 点击“插入”逐步演示比较、走左/右子树、挂到空位的过程（金色高亮新节点）。
  3. 点击“查找”播放路径动画：蓝色高亮查找路径，绿色命中，并显示比较次数。
  4. 点击“删除”移除指定值（双子节点用中序后继替换）。
  5. 先用下拉框选择前序（根左右）/ 中序（左根右）/ 后序（左右根），再点“遍历”：逐步高亮访问顺序；结束后三种遍历序列会同时列在结果区，当前选中的一行加粗高亮（BST 中序即升序）。
  6. 点击“重置”清空树。

代码同步与单步

右侧代码卡会随操作自动切换（插入 / 查找 / 删除 / 前序 / 中序 / 后序），并高亮正在执行的那一行。用「⏸ 暂停 / ⏭ 单步 / ▶ 连续」和速度滑块逐行观察；变量卡实时显示 current、target、比较次数、深度与路径，操作日志逐条追加（蓝=走向、绿=成功、粉=失败、金=结构变化）。

💡 树的高度和节点数会实时更新在画布下方。

🔗 线性结构（栈 / 队列 / 单链表）

功能简介：可视化栈、队列、单链表三种基础线性结构的核心操作，附带伪代码与操作日志。

操作步骤

  1. 顶部切换结构：栈（LIFO）、队列（FIFO）、单链表。
  2. 输入数值后点击操作按钮：栈/队列入出为 O(1)；链表「尾插」演示遍历过程，「按值删除」会先扫描定位再调整指针。
  3. 「查找」演示从头（栈从顶）逐个扫描的 O(n) 过程。
  4. 下方信息卡实时显示元素个数、头尾元素；伪代码区同步展示当前操作实现。

🔍 搜索与图

功能简介：包含两部分：二分搜索（有序数组）和 BFS/DFS 网格路径搜索。

二分搜索

  1. 系统自动生成一个有序随机数组，也可以在输入框里填自己的数组后点“应用”（会自动升序去重）。
  2. 在“目标值”框中输入要查找的数字。
  3. 点击“搜索”观看指针收缩过程，每一步高亮中间值；也可用“⏭ 单步 / ⏮ 上一步”逐步查看，右侧代码卡同步高亮当前执行行。
  4. 点击“重置”生成新数组。

网格 BFS / DFS / A*

  1. 点击格子可以切换障碍物（墙），起点固定在左上、终点在右下。
  2. 点击“BFS”“DFS”或“A*”开始寻路 —— 搜索基于当前你画的障碍，不会重置。
  3. BFS 保证最短路径但探索范围大；DFS 不保证最短；A* 用曼哈顿距离启发，又快又短。
  4. 点击“暂停”可随时暂停动画，再次点击继续。
  5. 点击“🎲 随机障碍”重新随机生成墙；点击“清空”移除所有墙。

🎯 算法挑战

功能简介：互动游戏，训练“下一步该做什么”的排序直觉，支持冒泡 / 选择 / 插入三种算法出题。

操作步骤

  1. 用顶部下拉框选择算法（出题规则随算法变化），再点“下一步”出题。
  2. 冒泡：点击两个相邻且左大右小的条形；选择排序：点出未排序区间里的最小元素；插入排序：点出当前 key 应该插入到的位置。
  3. 答对会交换并加分；答错会说明原因（例如“冒泡排序只能交换相邻元素”）。
  4. 挑战会持续到数组完全有序，然后自动生成新数组。
  5. 点击“重置”重新开始，计时器会重置。
💡 右上角显示得分（正确/总次数）和用时。

⚔️ 双算法竞技场

功能简介：同时运行两种排序算法，直观对比速度差异。

操作步骤

  1. 在“左算法”“右算法”下拉框里选两种算法（10 种算法全部可选）。
  2. 按需选择“规模”（20 / 30 / 50）与“速度”（极快 / 正常 / 慢放）。
  3. 点击“开始对决”，左右两侧同时开始排序。
  4. 实时观察比较次数、移动次数和进度百分比。
  5. 一方完成时显示“对决结束”，可直观看出哪种算法更快。
  6. 点击“重置”重新生成数组，准备下一轮对决。
💡 建议选择速度差异大的算法（如冒泡 vs 快速），效果更明显。

⌨️ 全局快捷键

  • Space — 暂停/继续（排序页面）
  • → — 下一步（排序中自动暂停并前进一帧）/ 回放前进（排序结束后）
  • ← — 上一步（排序中回看上一帧）/ 回放后退（排序结束后）
  • R — 重置数组（排序页面）
  • L — 双栏 / 单栏布局切换（任意页面）
  • T — 深色 / 浅色主题切换（任意页面）
  • 1 ~ 8 — 按顺序切换 8 个标签页
💡 刷新页面后会自动回到上次所在的标签页（也支持 URL hash，如 #bst）。

❓ 常见问题

  • 单步没反应？ 排序中点“下一步”会自动暂停并前进一帧；若已结束，则“下一步”用于回放游标。
  • 回放滑动条不出现？ 排序必须正常结束（未停止）才会生成回放数据。
  • 音效没声音？ 浏览器要求先与页面交互一次才允许播放音频，随便点一个按钮即可。
  • BST 插入没反应？ BST 不插入重复值，换个数字试试。
  • 竞技场对决不开始？ 确保两种算法都已选择，且页面未处于排序状态。
