# dsa-visual-lab · 算法可视化实验室

> 单文件 HTML、零依赖、纯前端的数据结构与算法可视化实验室。
> 双击 `index.html` 即可运行，无需安装、无需联网、无需后端。

![status](https://img.shields.io/badge/version-v5-f7c948) ![deps](https://img.shields.io/badge/dependencies-0-38ef7d) ![license](https://img.shields.io/badge/license-MIT-4facfe)

## 这是什么

一个给「学算法的人」用的可视化工作台。目标不是把算法画得好看，而是让**代码、变量、图形、解说在同一屏里对齐**——你单步走一步，就能同时看到图表怎么动、代码执行到哪一行、变量变成了什么、这一步为什么这么做。

适合：数据结构课程（408 / 考研 / 期末）、技术面试复习、课堂演示、自学转行。

## 核心功能

### 1. 排序可视化（10 种算法）
冒泡 / 选择 / 插入 / 希尔 / 归并 / 快速 / 堆 / 计数 / 桶 / 基数

- **双栏工作台**：左侧图表与控制，右侧代码 + 变量 + 解说 + 步骤时间线，滚动时右侧固定不动
- 开始 / 暂停 / 单步 / 停止 / 重置，1%~100% 无级调速
- 5~100 数据规模，随机 / 逆序 / 几乎有序 / 重复四种预设，支持手动输入数组
- 完成后可拖动回放任意历史步骤，也可点步骤时间线直接跳转
- 代码支持 **Python / C / Java** 三种实现（可一键复制），三种语言的当前执行行都会高亮
- 变量面板按算法自动过滤，只显示当前算法真正用到的变量
- 比较 / 交换音效（WebAudio 合成，无音频文件）
- 排序结束自动做结果校验（单调性 + 元素多重集一致性）

### 2. 二叉搜索树 BST
插入 / 查找 / 删除（含双子节点中序后继替换）/ 前中后序遍历。
查找路径逐步高亮，命中变绿，同步显示比较次数、路径、树高；右侧代码卡随操作切换并高亮当前语义行，支持单步调试与操作日志。

### 3. 线性结构
栈（LIFO）/ 队列（FIFO）/ 单链表，可视化入出、尾插、按值删除、查找，配伪代码与操作日志。

### 4. 搜索与图
二分搜索（指针收缩 + 自定义数组 + 单步）与 10×10 网格 **BFS / DFS / A*** 寻路（可手绘障碍、可暂停，对比探索格子数与路径长度）。

### 5. 算法对比
十大排序的时间/空间复杂度、稳定性、类别对照表 + 复杂度增长曲线 + 稳定排序记忆卡片。

### 6. 算法挑战
给一组乱序条形，点出「应该交换的两个条形」，即时判分计时，支持切换算法出题。

### 7. 双算法竞技场
左右两个算法在同一组数据上同速对决，实时比较次数 / 交换次数 / 进度。

### 8. 统计与分享
多次运行统计（平均/最小/最大耗时、比较与交换次数折线图）、五维性能雷达图、iframe 嵌入代码生成。

## 使用方式

**本地运行**：下载 `index.html`，双击用浏览器打开。

**在线体验**：https://zhenglang24.github.io/dsa-visual-lab/

### 快捷键

| 键 | 作用 |
|---|---|
| `Space` | 开始 / 暂停 |
| `→` | 单步（排序中）或前进一帧（回放中） |
| `←` | 回退一帧（回放中） |
| `R` | 重置 |

## 技术说明

- 单个 HTML 文件，原生 JavaScript + Canvas + CSS，**零第三方依赖、零构建、零 CDN**
- 不使用 Cookie、不埋点、不采集任何数据；所有计算在浏览器本地完成
- Canvas 按 devicePixelRatio 绘制，高分屏不模糊；自适应窗口尺寸
- 支持深色 / 浅色主题，布局（双栏 / 单栏）、主题、上次所在页面都会记住
- 兼容 Chrome / Edge / Firefox / Safari 近两年版本；桌面端体验最佳，移动端可用

## 已知限制

- 基数排序对**负数**处理不正确（当前实现按绝对值取位，负数会排到错误位置）。教学演示负数请用其它算法。
- 计数排序 / 桶排序适合整数且范围较小的数据。
- 动画为教学演示用，速度受 `setTimeout` 精度影响，耗时统计仅供参考。
